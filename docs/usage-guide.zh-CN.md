# Inkwell 中文使用说明

Inkwell 是 SillyTavern 与 TauriTavern 的聊天配图扩展。助手回复到达后，由语言模型挑选值得配图的段落并为每段写出标签，Inkwell 再把这些标签组装成图片提示词，交给所配置的图像服务生成，图片显示在对应段落下方。本文面向安装和使用扩展的用户，内容以当前源码为准。

## 1．运行要求

| 项目            | 最低要求                          | 用途                                       |
| --------------- | --------------------------------- | ------------------------------------------ |
| 宿主            | SillyTavern 1.18.0 或 TauriTavern | 扩展宿主                                   |
| JS Slash Runner | 4.9.1                             | 段落分析、改写消息文本和读取世界书         |
| 浏览器存储      | 可用的 IndexedDB                  | 保存图片、任务记录、素材库和本机加密的密钥 |

Inkwell 启动时会探测所需的宿主能力。JS Slash Runner 缺失、被禁用或版本过低时，扩展显示阻止页并给出最低版本和安装地址，不会进入功能不完整的界面。

## 2．安装与打开

在宿主的第三方扩展安装界面中先安装 JS Slash Runner，仓库地址如下：

```text
https://github.com/N0VI028/JS-Slash-Runner
```

再用同一界面安装 Inkwell：

```text
https://github.com/ITOTI-Y/tavern-canvas
```

宿主从仓库根目录读取 `manifest.json`，直接加载已提交的 `dist/index.js` 与 `dist/index.css`，不需要在宿主机器上构建。安装后刷新页面。

打开 Inkwell 的入口有三个。扩展面板中有 Inkwell 区块，其中的按钮打开工作室；在聊天输入框中执行 `/inkwell` 也可以打开；在“设置 > 通用 > 外观”中开启“显示悬浮入口按钮”后，页面上会出现一个可拖动的悬浮按钮。宿主没有扩展面板时，悬浮按钮始终显示。

工作室分为“设置”和“图库”两个视图。设置包含插图、图像服务、翻译、提示词预设、素材库、连接、通用和诊断八个分区。语言、主题和检查器宽度位于“设置 > 通用 > 外观”。

## 3．配置图像服务

### 3.1 选择密钥存储方式

“设置 > 通用 > 密钥存储”决定 API 密钥保存在哪里。扩展设置、服务配置和归档只保存密钥的引用，不保存明文。

| 存储方式             | 密钥位置                                | 读取条件                                              |
| -------------------- | --------------------------------------- | ----------------------------------------------------- |
| 本机加密存储（默认） | IndexedDB，用浏览器内不可导出的密钥加密 | 在当前浏览器中随时可读                                |
| SillyTavern 密钥库   | 宿主的 `secrets.json`                   | 需要在 `config.yaml` 中设置 `allowKeysExposure: true` |
| 浏览器加密库         | IndexedDB，用口令派生的密钥加密         | 每次刷新页面后输入口令解锁                            |

直连云端服务时，扩展需要读回明文密钥。选择 SillyTavern 密钥库时，宿主默认拒绝读取，开启 `allowKeysExposure` 后同一页面中的任何脚本都能读取全部已存密钥。TauriTavern 默认同样关闭该开关，因此扩展默认使用本机加密存储，不需要改动宿主配置。切换存储方式不会迁移已有密钥，切换后需要重新填写。

### 3.2 添加服务配置

1. 打开“设置 > 图像服务”，单击“添加图像服务配置”。
2. 填写名称，选择服务类型，填写模型 ID，然后保存。
3. 在配置行中单击“设置 API 密钥”。明文只交给当前选择的密钥存储方式。
4. 在要使用的配置上单击“设为默认”，配图请求使用默认配置。

可用于聊天配图的服务包括 NovelAI、OpenAI Image、Google Image 和 SD WebUI。ComfyUI 有适配器和工作流素材，但当前不能用于聊天配图。SD WebUI 直连只接受回环地址，例如 `http://127.0.0.1:7860`；由于配置表单没有 `base_url` 字段，全新安装时 SD WebUI 需要经 Gateway 使用。

### 3.3 NovelAI 参数与账户

默认配置为 NovelAI 时，“设置 > 图像服务”下方显示该配置的生成参数，包括模型、尺寸、步数、采样器，以及要随请求发送的氛围迁移图片。这些参数对该配置的每次配图生效。某个模型不支持的参数会标为已忽略，例如 V5 没有氛围迁移。质量标签和 UC 预设见下一节。

账户区域从 NovelAI 读取订阅等级、Anlas 余额和 Opus 的 V5 免费额度。配图对话框按 NovelAI 网页端的公式估算费用，Opus 订阅在 1024 × 1024 像素以内、28 步以内的单张图免费；实际扣费以 NovelAI 服务器为准。氛围迁移图片按模型和信息提取度编码一次后缓存在浏览器中，因为每次编码需要 2 Anlas。

### 3.4 质量标签与 UC 预设

每个图像服务配置都有一个质量标签预设和一个 UC（不想要的内容）预设。它们以标签按钮的形式显示在三个位置：配图对话框的共享提示词框下方（质量标签）和负向提示词框下方（UC 预设）、槽位“编辑提示词”的同一位置，以及“设置 > 图像服务”中每个配置的下方。单击按钮会列出 NovelAI 前端各模型的内置预设及其完整标签，之后是自定义预设；右侧的勾号用于开关。

发送请求时，质量标签加在正向提示词末尾，UC 预设加在负向提示词前面，所有图像服务都会注入，标签不会写进提示词框。在任何一处修改都会保存到当前配置，之后的配图（包括自动配图）都按新选择注入。NovelAI 配置默认使用其模型的 Standard 质量标签和 Heavy UC，其他服务默认两者都关闭。少数 NovelAI 模型锁定了自己的 UC 预设，这些模型不再注入 UC。

自定义预设在“设置 > 提示词预设”页下方管理：填写名称，选择类型（质量标签或 UC 预设），填写用逗号分隔的标签后保存。

## 4．段落分析设置

“设置 > 插图”控制段落分析和生成的方式。

分析请求经过一个 SillyTavern 聊天补全预设发出，留空时使用当前加载的预设。预设中的破限、混淆和输出格式要求会原样作用于分析请求；如果模型没有返回所需的 JSON，配图对话框会提示更换预设。分析连接可以是 SillyTavern 当前 API、某个代理预设，或兼容 OpenAI 接口的自定义 API；自定义 API 的密钥与其他密钥存放在同一后端。

“随分析发送的聊天记录条数”决定模型能看到多少上文。“世界书”有三个选项：

- 当前聊天的世界书（默认）：由 SillyTavern 按聊天记录激活条目，包括全局、角色和聊天绑定的世界书。
- 指定世界书：只使用所选的一本世界书，发送其中的常驻条目和被待分析回复的关键词激活的条目，并替换 SillyTavern 自己激活的条目。拉丁字母关键词按整词匹配，中日韩文字按子串匹配；向量化条目、递归激活、触发概率和定时效果不生效。
- 不使用：分析请求中不包含任何世界书内容。

其余选项包括每条回复最多配图数、组装图片提示词时使用的提示词预设、同时生成的图片数，以及服装判断使用的模型（见 6.2 节）。服装判断默认使用分析连接的模型；分析连接为 SillyTavern 当前 API 时不能另选模型。NovelAI 会以 429 拒绝同一账户同时到达的多个生图请求，因此发往 NovelAI 的请求之间至少间隔 1.5 s，账户允许时各请求并行进行。订阅账户在一张图生成期间会拒绝新的请求，这时被拒绝的请求等待后重新发送，等待时间从约 2 s 开始逐次加倍，单次最长 15 s，NovelAI 给出更长的 Retry-After 时按其等待；六次重试后仍被拒绝才判为失败。被拒绝的请求没有生成图片，NovelAI 也不扣 Anlas。

“配图引导”和“服装引导”是两个独立的文本框，用来写出对画面和衣着的固定要求，例如画风、季节、时代或场所。配图引导附在每次段落分析请求的末尾，影响分析写出的场景和画风标签；服装引导附在每次服装判断请求的末尾，影响为角色选择或新建的服装。回复中明确写出的内容优先于引导。留空时请求不附加任何引导。

## 5．为回复配图

### 5.1 自动配图与手动配图

开启“设置 > 插图 > 每条回复后自动配图”后，每条新的助手回复都会被分析，选中的段落随即开始生成。关闭时，每条回复旁有“为这条回复配图”按钮。单击后，对话框列出分析选中的段落，每段显示共享提示词（场景与画风）、各角色的提示词和负向提示词。提示词可以直接修改。每个提示词框右上角有两个图标：“译为英文标签”把框内的中文转换为标签，“中文核对”在框下方显示各标签的中文含义，开启期间随修改自动更新。在提示词框中输入时，框下方列出与当前标签匹配的词库标签及其中文名，圆点越实表示标签越常用；输入中文也能找到对应的英文标签，单击建议或按 Tab 插入，方向键选择后按 Enter 也可插入。词库第一次使用时需要约 1 分钟准备内置词库，期间不显示标签建议，中文核对只使用术语库和 DeepL。使用 NovelAI 时对话框显示每张图和合计的 Anlas 估算，确认后才开始生成。

对话框下方的“自选段落”列出这条回复中还没有槽位的段落。勾选后单击“为所选段落写提示词”，分析模型只为这些段落写提示词，结果作为新的槽位加入对话框并默认勾选；模型漏掉的段落同样加入，提示词留空，可以自行填写。自动配图开启时，这个按钮也可以为已配图的回复补充段落。

段落分析的请求失败，或模型的回复无法解析时，Inkwell 会在 2 s 和 4 s 后各重试一次，三次都失败才在回复下方显示失败原因。失败提示带有“重新分析”按钮：自动配图开启时，单击后重新分析并生成；关闭时，单击后打开配图对话框。

### 5.2 图片槽位

每个选中的段落下方有一个图片槽位。槽位保留该段生成过的所有图片，可以重新生成、编辑提示词并在图片之间翻页。刷新页面会中断正在进行的生成，槽位会标出中断状态。

NovelAI 生成的图片在槽位中还提供快速编辑：图生图、局部重绘、放大，以及 Director 工具中的线稿、草图、上色、更换表情、去杂物和去除背景。放大要求原图不超过 100 万像素。

## 6．素材库

“设置 > 素材库”保存在多次生成中复用的内容，分为词库、角色、服装、LoRA、氛围迁移和工作流六个分页。条目支持搜索、拖动排序和删除。

### 6.1 角色与服装的自动匹配

角色条目按年龄、体型、肤色、发型、眼睛、妆容、默认表情和特征八个槽位填写外观标签，另外可以填写别名、性别（女性、男性或其他）、排除特征和默认服装。服装条目按连身装、外套、上衣、下装、腿部、鞋履、头饰和配饰八个槽位填写标签，并可关联到一个角色。

段落中出现素材库角色的名称或别名，或分析模型报告了该角色时，Inkwell 用角色条目中的外观标签替换模型自己写的外观标签，再加上该角色在这条回复中所穿的服装（见 6.2 节）。分析模型已经为角色写了标签时，条目中的表情不加入提示词，以免覆盖段落描写的神情。拉丁字母名称按整词匹配，中日韩文字名称按子串匹配。

使用 NovelAI V4 及以上模型时，每个角色有独立的角色提示词，角色条目中的“排除特征”作为该角色自己的负向提示词，例如为人类角色排除另一角色的尖耳。这样多个角色同时出现时，外观不会互相混合。

### 6.2 服装追踪与自动建档

每条新的助手回复生成后，Inkwell 经分析预设发送一次结构化的服装判断请求，记录这条回复中各角色穿的服装、脱下或替换的槽位，以及湿衣服、头发凌乱这类临时状态。判断结果保存在这条回复当前的候选回复上。没有自己记录的回复沿用之前最近一条回复的记录，因此角色换装后，后续回复一直使用新服装，直到剧情再次改变。聊天中尚无记录的角色穿默认服装，未设置默认服装时穿第一套关联服装。回复中出现了一个还没有任何服装的角色时，请求的结构会要求模型按剧情或角色设定返回该角色当前的衣着，Inkwell 据此建立这个角色的第一套服装；新建档的角色同样随档案返回衣着。服装判断失败时，回复沿用上一条的服装，聊天中会显示失败原因。

同一请求还会为素材库中没有的具名角色和服装建立条目。这些条目标记为由服装判断建立，只在当前聊天中出现，编辑表单中的“导入全局素材库”按钮可以把它们移入全局素材库。对于已有角色，模型只能填写空的外观槽位；用户编辑过的槽位会被锁定，模型不会再填写。

配图对话框在每个素材库角色的提示词下方显示服装选择框和临时状态输入框。修改后，对话框中各段提示词里的旧服装标签替换为新标签，修改同时保存为这条回复的服装记录，后续回复会沿用。

### 6.3 角色参考图

参考图位于角色编辑表单的第一行，可以上传图片，也可以单击“生成参考图”用默认的图像服务配置生成。生成时，提示词预先填入性别、全身站姿和白色背景等构图标签、外观各槽位和默认服装的标签，负向提示词填入排除特征，两者都可以先修改；生成的图片同时保存在图库中，质量标签和 UC 预设照常注入。角色还没有任何服装时，生成完成后会询问是否根据该图生成服装；确认后，服装判断使用的模型识别图中的衣着，按八个槽位建立一套服装，关联到该角色并设为默认服装，最后需要保存角色才会记住默认服装。这一步要求该模型支持图片输入，例如 GPT-4o、Claude 或 Gemini 系列；不支持图片的模型会报错。无论上传还是生成，参考图的长边都会缩小到 1536 px 以内后随条目保存。只有勾选“用 NovelAI 出图且画面中有该角色时随请求发送”后，参考图才会随请求发出，并按所选用途使用：

- 氛围迁移：作为氛围迁移参考图随请求发送，强度 0.6。V5 模型不支持氛围迁移，此时参考图不发送。
- 图生图：以参考图为底图生成，强度 0.7。多个角色都选择图生图时只使用第一个。
- 人物参考：作为 NovelAI 的角色参考（Precise Reference）发送。只有 V4.5 模型支持，每张图另加 5 Anlas，并且不能与氛围迁移同时使用，因此发送人物参考时不再发送任何氛围迁移图片。多个人物参考会被混合成一个人，所以多个角色都选择人物参考时只发送第一个。

### 6.4 LoRA

LoRA 条目记录 SD WebUI 中的文件名（不含扩展名）、权重和触发词，并关联到一个角色。用 SD WebUI 出图且画面中有该角色时，请求会附加 `<lora:文件名:权重>` 和触发词。未关联角色的 LoRA 不会自动附加，NovelAI 等其他服务不受影响。

### 6.5 氛围迁移、工作流与词库

氛围迁移分页保存 NovelAI 氛围迁移图片及其强度和信息提取度，在“设置 > 图像服务”中按 NovelAI 配置勾选使用。工作流分页导入 ComfyUI 工作流 JSON 并映射占位符。词库分页安装和搜索标签包，配图对话框的中文转标签也使用这些词库；包格式和更新方式见[词库包说明](vocabulary-packages.md)。可能包含成人内容的词库包默认隐藏，需要手动开启披露选项。

## 7．翻译

“设置 > 翻译”配置 DeepL。DeepL 不接受来自浏览器页面的请求，翻译经 SillyTavern 的 DeepL 接口转发；密钥保存在 SillyTavern 密钥库中，与 SillyTavern 自带的翻译扩展共用，免费版与付费版密钥使用不同的接口。术语表和词库中的中文译名优先替换，剩余部分才发给 DeepL。

## 8．Gateway

Gateway 是本仓库中可自托管的服务，厂商密钥保存在 Gateway 主机上，浏览器只持有 Gateway 的访问令牌。部署、环境变量、CORS、HTTPS 和备份见 [Gateway 运维文档](gateway.md)。

1. 在 Gateway 主机上完成服务和 Bearer 令牌配置，确认 `/healthz` 可以访问。
2. 在 Inkwell 中添加对应服务类型和模型的配置，模型需包含在 Gateway 的 `model_allowlist` 中。
3. 打开“设置 > 连接”，填写 Gateway 地址，例如 `http://127.0.0.1:8787`。
4. 使用 `http://` 地址时阅读风险提示并确认。确认按规范化的 origin 分别记录，更换地址后需要重新确认。
5. 填写 Gateway 访问令牌并保存，明文交给当前的密钥存储方式。

配置 Gateway 后，所有图片生成都经过 Gateway；清空地址后恢复直连。回环地址上的明文 HTTP 流量不会离开本机，局域网或公网部署应使用 HTTPS 反向代理，否则令牌、提示词和图片都以明文传输。

## 9．图库与诊断

“图库”视图可以按服务、置顶、孤立状态和时间范围筛选图片。单击缩略图打开预览，可置顶、下载、删除或解除与消息的关联；解除关联只移除图片与消息之间的关系，图片仍保留在图库中。图片中含有可识别的嵌入参数时，详情显示 seed、模型和提示词，并可复制参数。

“设置 > 诊断”显示 JS Slash Runner 和 Gateway 协议版本、宿主能力矩阵、Gateway 连接测试、任务时间线和浏览器存储占用。支持包在本地生成并下载，包含版本、能力矩阵、脱敏后的设置、错误代码和任务时间线，不包含提示词、消息内容、密钥或图片。

## 10．备份

“设置 > 通用 > 数据”可以导出归档。归档是 ZIP 文件，包含清单、校验和、每个存储一份 JSONL 记录和按内容寻址的图片，不包含明文密钥、Gateway 令牌、日志和支持包。归档只覆盖当前命名空间，不包含保存在宿主扩展设置中的语言、并发和 Gateway 地址等设置，也不包含 Gateway 自己的数据。

导入归档会把记录合并到当前数据中，不删除已有数据；与归档中 id 相同的记录会被归档版本替换，因此在同一台设备上导出后再导入，可以把改坏的条目恢复成备份时的样子。扩展先在临时区域按校验和检查全部记录和图片，通过后才合并；归档损坏或导入被取消时，当前数据保持不变。

## 11．TauriTavern

TauriTavern 是优先适配的宿主。在 TauriTavern 的“设置 > 性能”中开启聊天 DOM 虚拟化后，宿主会先弹出 ChatSurface 渲染扩展的确认窗口；确认后 Inkwell 作为 ChatSurface 参与者注册，消息滚出视口再滚回时图片槽位会自动恢复。未开启虚拟化时 Inkwell 按普通方式渲染槽位。

TauriTavern 没有 `/proxy` 路由。NovelAI 出图和账户查询可以直接从页面访问 `image.novelai.net`，不依赖代理。TauriTavern 默认关闭“允许显示密钥”，使用默认的本机加密存储即可，无需开启该选项。

## 12．数据与隐私

生成的图片、提示词预设、素材库条目、词库包和任务记录保存在浏览器 IndexedDB 数据库 `tavern_canvas_v3` 中，图片按 SHA-256 内容寻址。扩展设置保存在宿主扩展设置的 `tavern_canvas` 项中。本机加密存储和浏览器加密库的密文分别保存在独立的 IndexedDB 数据库中，不进入业务数据库和归档。

项目没有遥测和统计。网络请求只发往所配置的图像服务、Gateway、分析连接，以及打开词库分页时的词库目录。清除浏览器站点数据会同时删除业务数据库和加密的密钥。

## 13．常见问题

| 现象                             | 原因                                                  | 处理方法                                                       |
| -------------------------------- | ----------------------------------------------------- | -------------------------------------------------------------- |
| 启动后只显示阻止页               | JS Slash Runner 缺失、被禁用或低于 4.9.1              | 安装或升级 JS Slash Runner，启用后刷新页面                     |
| 段落分析失败，提示没有找到 JSON  | 预设规定了自己的输出格式，或对回复做了混淆            | 在“设置 > 插图”中换用其他预设                                  |
| 直连云端服务时提示无法读取密钥   | 选择了 SillyTavern 密钥库且未开启 `allowKeysExposure` | 改用本机加密存储并重新填写密钥，或在宿主中开启该开关           |
| 提示浏览器加密库已锁定           | 页面刷新后口令派生的密钥已从内存清除                  | 在“设置 > 通用 > 密钥存储”中输入口令解锁                       |
| 多个角色的外观混在一起           | 角色未保存在素材库，或模型不支持角色提示词            | 为角色建立素材库条目并填写排除特征，使用 NovelAI V4 及以上模型 |
| 角色参考图没有效果               | 未勾选随请求发送，或所选用途不被当前模型支持          | 勾选发送选项；人物参考需要 V4.5，氛围迁移不支持 V5             |
| LoRA 没有附加                    | LoRA 未关联角色、画面中没有该角色或服务不是 SD WebUI  | 在 LoRA 条目中关联角色，并使用 SD WebUI 配置                   |
| 指定世界书后条目没有生效         | 回复中没有出现条目关键词，或条目为向量化条目          | 检查关键词；需要常驻的条目在世界书中设为常量                   |
| Gateway 已配置但任务提示没有令牌 | 只填写了地址，尚未保存访问令牌                        | 在“设置 > 连接”中填写并保存令牌                                |
| Gateway 提示明文来源未确认       | 使用了未确认的 `http://` origin                       | 阅读风险提示后确认，或改用 HTTPS                               |
| 浏览器存储接近配额               | 图片占用较多                                          | 先导出归档，再在图库中删除不需要的图片                         |

项目的构建、测试和发布命令见[项目 README](../README.md)。
